你好，我是 KitanoSakura 一名某个机电大学的水货开发者 你也可以叫我北野~。

大概从初一开始就喜欢折腾这些有的没的。那时候第一次接触建站，找了台免费的EP主机，照着社区（芥子社区还是没得太早了，我的版主之位啊！）的教程一步一步通过 `MT管理器` `网页CODE` 写出来了自己第一个PHP页面，当时的那种成就感现在还记得——屏幕上出现自己写的页面的那一瞬间，比考试考了满分还开心（虽然现在看来很丑）。

后来慢慢入了二次元的坑，五等分的花嫁、鸟之诗、Fate系列、崩坏：星穹铁道、绝区零，一个也没落下。再后来发现，把喜欢的角色、喜欢的画面，用自己喜欢的code方式重新「表达」出来，是一件特别有意思的事。不是那种"完成任务"的快感，而是一种……怎么说呢，像是在给自己喜欢的世界添砖加瓦。

现在日常做的事情大概是这些：

- 写点前端页面，试着把脑子里的画面，想法一个个实现出来
- 用 `IDA` 实现逆向工程，还有一些通过逆向写出来的小Tool（💩一样）
- 使用 `C#` 实现一些游戏服务器研究和开发
- 平常也会用用 `Python` / `Shell` 小脚本处理一些重复劳动
- 逛 GitHub，LinuxDO等社区，看到有意思的项目就拉下来研究一番

> 不追求写出多好，多完美的代码，只希望做出来的东西自己看着舒服、用着顺手。
